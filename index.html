Was Krawl kann

Krawl erkennt bösartige Angreifer, Web-Crawler und automatisierte Scanner, verlangsamt sie und analysiert ihr Verhalten – mit realistischen Fake-Webanwendungen als Köder.

🕵️

Deception Server

Realistische Fake-Webapps mit verlockenden Zielen: Admin-Panels, Config-Dateien, Fake-Zugangsdaten.

🤖

KI-Fake-Seiten

Unbekannte Pfade werden per LLM mit realistischen Seiten beantwortet – gecacht in der SQLite-DB.

🐢

Scanner verlangsamen

Konfigurierbare Antwortverzögerung (KRAWL_DELAY) nervt und bremst automatisierte Angreifer aus.

📊

Dashboard

Geschütztes Dashboard mit Analyse von Angreifern und generierten Deception-Seiten.

⚙️

Single Container

Standalone-Modus (SQLite + In-Memory-Cache) – keine externen Dienste nötig.

🔁

Auto-Updates

Täglicher Upstream-Check baut neue Krawl-Versionen automatisch und pusht sie nach GHCR.

Deploy mit Portainer

Git-Deployment: GitHub Actions baut das Image bei jedem Push auf main und pusht es auf ghcr.io/jbkunama1/hai.krawl (multi-arch linux/amd64 + linux/arm64). Manuell anstoßbar unter Actions → „Build & Push Docker Image to GHCR“ → Run workflow.

1

In Portainer → Stacks → + Add stack öffnen.

2

Name: krawl · Build method: Repository.

3

Repository URL: https://github.com/jbkunama1/hAI.Krawl · Reference: refs/heads/main.

4

Compose path: docker-compose.yml.

5

Environment-Variablen setzen (siehe Tabelle unten).

6

Deploy the stack – Portainer pullt das vorgebaute Image (pull_policy: always), kein Build auf dem Host.

Voraussetzungen

✅ Portainer CE/Business ≥ 2.x

🌐 Internet-Zugriff vom Docker-Host

🔓 Einmalig: GHCR-Paket hai.krawl auf public setzen (Repo → Packages → Change visibility), sonst braucht Portainer Login-Credentials.

Environment Variables

Wichtige Variablen für deinen Stack – die komplette Liste steht in der README. Eine Vorlage liegt als .env.example im Repo.

VariableBeschreibung
KRAWL_DASHBOARD_SECRET_PATHDashboard-Pfad (muss mit / beginnen). Zufälligen Wert setzen! Default: /home/KRAWL
KRAWL_DASHBOARD_PASSWORDFestes Passwort für geschützte Panels – sonst generiert Krawl eines (steht in den Container-Logs).
KRAWL_DELAYAntwortverzögerung in ms (z.B. 500), bremst Scanner aus.
KRAWL_CUSTOM_TEMPLATE_PATHPfad im Container zu einer eigenen HTML-Fake-Seite (Template mit {counter} + {content}).
KRAWL_AI_ENABLEDKI-Fake-Seiten aktivieren (true/false). Default: false
KRAWL_AI_PROVIDERopenrouter oder openai (für OpenAI-kompatible Endpoints wie 9router).
KRAWL_AI_OPENAI_BASE_URLBasis-URL für Provider openai (self-hosted / 9router).
KRAWL_AI_MODELKI-Modell, z.B. free bei 9router.
KRAWL_AI_MAX_DAILY_REQUESTSKostenbremse pro Tag (0 = unbegrenzt). Default: 100
PORTHost-Port (Container-Port ist 5000).

KI-generierte Deception-Pages

Krawl beantwortet unbekannte Pfade per LLM mit realistischen Fake-Seiten statt statischer Templates. Generierte Seiten werden in der SQLite-DB gecacht (Dashboard → Tab Deception).

🔌

9router (empfohlen)

KRAWL_AI_ENABLED=true · KRAWL_AI_PROVIDER=openai · KRAWL_AI_OPENAI_BASE_URL=https://9router.arbeitermili.eu/v1 · KRAWL_AI_MODEL=free

🌐

OpenRouter

Kostenloses Konto auf openrouter.ai, Key setzen. Free-Modelle wie nvidia/nemotron-3-super-120b-a12b:free – kein Guthaben nötig.

🏠

Self-hosted LLM

Eigener Ollama/llama.cpp-Container im selben Netz: KRAWL_AI_OPENAI_BASE_URL=http://krawl-llm:8080/v1 – keine Kosten.

💰 Kostenbremse: KRAWL_AI_MAX_DAILY_REQUESTS. Offizielle Kosten ~$0.001/Seite – mit Free-Modellen oder self-hosted kostenlos.
